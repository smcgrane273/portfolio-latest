Identity / Typography / Social Assets

ONE Pilates

Visual assets for a Pilates studio, using oversized typography and movement imagery to build a calm, flexible brand language.

Studio

Detail Studio

Format

Social Graphics / Image System

Focus

Movement / Type / Image

Context

Through my work with Detail Studio, I had the opportunity to help develop visual assets for ONE Pilates, a new studio focused on movement and flow. This project was especially meaningful to me because it marked my first sustained experience working with typography.

What initially felt unfamiliar quickly became confidence-building and creatively expansive. I worked on imagery and graphics for social media, shaping a visual language drawn from the studio's symbols and philosophy.

Typographic System

By exploring type as form and integrating it directly into images, the assets use the letters in ONE as graphic structures. The body moves through and around the typography, making the letterforms feel physical rather than simply placed on top.

Reflection

The project helped me understand typography as something active: a structure that can hold movement, frame an image, and quietly shape how a brand feels.
